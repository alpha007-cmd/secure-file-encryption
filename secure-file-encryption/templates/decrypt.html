What happens during decryption:

  1. The encrypted package is parsed
  2. The AES key is recovered using RSA-3072 private key
  3. AES-GCM authentication verifies the data is untampered
  4. The file is decrypted
  5. SHA-256 is recalculated and compared
  6. Only if all checks pass is the file made available
