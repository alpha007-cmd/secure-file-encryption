🔑 AES-256-GCM

Purpose: Encrypts the actual file data.

Why: Symmetric encryption is fast and efficient for large amounts of data.

Bonus: GCM mode provides built-in authentication, meaning any modification is detected automatically.

🔐 RSA-3072-OAEP

Purpose: Protects the AES encryption key.

Why: Asymmetric encryption is ideal for protecting small pieces of data like encryption keys.

OAEP padding with SHA-256 provides secure, randomized encryption of the key.

#️⃣ SHA-256

Purpose: Additional integrity verification.

Why: Provides an independent hash comparison between the original and decrypted file to confirm data integrity.

🔄 Hybrid Cryptography

AES = Fast file encryption

RSA = Secure key protection

Together = Best of both worlds — speed of symmetric encryption with the key-management advantages of asymmetric encryption.
