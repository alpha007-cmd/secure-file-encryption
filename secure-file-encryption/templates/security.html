AES-256-GCM

Purpose: Encrypts the actual file data.

Why: Symmetric encryption is fast and efficient for large amounts of data.

Bonus: GCM mode provides built-in authentication.

RSA-3072-OAEP

Purpose: Protects the AES encryption key.

Why: Asymmetric encryption is ideal for protecting small keys.

SHA-256

Purpose: Additional integrity verification.

Why: Independent hash comparison between original and decrypted files.

HYBRID

AES = Fast file encryption

RSA = Secure key protection

Result = Speed of symmetric + Security of asymmetric.
