Maximum file size: 50 MB

What happens during encryption:

  1. A random AES-256 key (32 bytes) is generated
  2. A random 12-byte nonce is generated
  3. Your file is encrypted using AES-256-GCM
  4. SHA-256 hash of the original file is calculated
  5. The AES key is encrypted using RSA-3072-OAEP
  6. Everything is packaged into a secure .enc file
